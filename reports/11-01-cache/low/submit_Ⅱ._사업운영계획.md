## Ⅱ. 사업운영계획

### Ⅱ.1 일반 현황
o 주관 (주)마인드스토리, 구성사 (주)가르침에듀·아시아밝음공동체
- 구성사 역할분장: [확인 필요: 사람이 정함]
o 사업총괄책임자 아래 상담지원팀·언어소통교육팀·운영지원팀 편성
- 총괄책임자: 통일부 협의·보고·인력관리 [확인 필요: 성명·자격]
- 상담지원팀: 심리검사·상담·코칭, 마음숲 상주 [확인 필요: 인원·자격]
- 언어소통교육팀: 의사소통 교육, 강의실 배치 [확인 필요: 인원·자격]
- 운영지원팀: 홈페이지·홍보·시설·회계, 회계책임자 별도 지정
o 종합심리검사·웩슬러지능검사, 인지·언어·놀이·미술치료 수행
- 갈등조정지도사·독해력지도사·놀이심리상담사 자격과정 운영
- 채용 시 북한이탈주민 상담 경력자 우선 [확인 필요: 자격 기준]
- 책임자·운영인력 변경 시 통일부 사전승인
- 인건비는 위탁사업비 총액의 30% 이내

### Ⅱ.2 프로그램 운영 계획
o 운영 방향: 정착을 막는 마음 문제와 말 문제를 함께 다루는 '마음숲·말숲' 두 축
- 신규 상담지원·교육 프로그램 포함 시 평가 우대
- 기존형(상담·언어교육)에 신규 프로그램을 더해 대상·형식 균형 편성
o 수요조사·설문 반영 콘텐츠 개발
- 수요조사 → 위탁 개시 직후 참여 희망자 설문·면담 → 수요조사 결과표
- 콘텐츠 조정 → 분기 설문 결과로 주제·회차 수정 → 프로그램 개정안
- 신규 과정 시범 → 소규모 시범 후 설문 → 정규 편성 검토서
o 공간별 테마
- 상담센터 마음숲(4층), 강의실(1~4), 미술실·음악실(3층), 요리교실(4층), 대강당(1층)
- 마음숲=치유, 강의실=말, 미술·음악실=표현, 요리교실·체육관=교류, 대강당=행사
o 상담센터 마음숲: 마음 치유
- 개인 심리상담 → 심리검사·해석 후 회기 상담 → 상담기록지·검사 해석지
- [신규] 정착 마음코칭 → 취업·관계 목표 세우기 코칭 → 개인 실행계획서
- [신규] 가족 마음 잇기 → 부모·자녀 검사·양육 상담 → 가족 상담기록지
o 미술실·음악실: 정서 표현
- [신규] 그림으로 만나는 나 → 미술심리·도형심리 집단 활동 → 활동지·작품집
- 미술 심리 기반 집단 프로그램(2024 전남 일자리종합센터) 운영
- [신규] 소리로 쉬는 마음 → 음악 활용 정서 이완 집단 → 정서 체크지
o 강의실: 말과 소통
- 남북 말 차이 교실 → 생활어·외래어·억양 차이 학습 → 낱말 학습장·수료 기록
- [신규] 생활문서 읽기 → 고지서·계약서 읽고 질문하기 → 읽기 점검지
- 독해력지도사 양성 과정(2025 여수 시립환경도서관) 운영
- [신규] 일터 말하기 → 면접·업무 보고 역할극 → 말하기 평가지
- [신규] 갈등 대화 연습 → 남북 주민 함께 갈등 상황 대화 실습 → 대화 기록지
- 갈등조정지도사 자격과정 운영
o 요리교실·다목적체육관: 남북주민 교류
- [신규] 남북 밥상 말나눔 → 남북 주민 짝지어 요리하며 낱말 나누기 → 남북 낱말 카드
- [신규] 함께 노는 가족 → 북한이탈주민·지역 가족 놀이 활동 → 관찰지·활동 사진
- 다문화 소통 프로그램(2022 교육나눔본부), 사회성놀이 프로그램 운영
o 대강당: 행사
- [신규] 말과 마음 발표회 → 연말 참여자 말하기·작품 발표 → 행사 결과보고서
o 다양성·균형성
- 영역 균형: 심리 프로그램과 언어 프로그램을 같은 비중으로 편성
- 형식 균형: 개인(상담)·집단(교육)·남북주민 함께(교류·행사)
- 북한이탈주민과 일반주민이 고른 혜택을 받도록 참여 기준 마련
- 목표 참여 인원·회차 [확인 필요: 프로그램별 목표치]
o 운영인력
- 상담·코칭은 상담지원팀, 언어·교류는 언어소통교육팀, 행사는 운영지원팀
- 과정별 외부 강사 [확인 필요: 강사 명단·자격]
o 운영일정
- 2027. 1월 위탁 개시
- 2027 상반기: 수요조사, 기존형 운영, 신규 과정 시범
- 2027 하반기: 설문 반영해 신규 과정 정규 편성, 연말 발표회
- 2028: 지속 참여자 심화 과정, 가족·교류 프로그램 확대
- 직장인 참여용 평일 저녁·주말 반 [확인 필요: 운영 시간]
- 매분기 종료 후 14일 이내 운영결과 중간보고
o 홍보
- 관련 홈페이지 운영은 위탁사무
- 홈페이지 안내 → 과정 안내·신청 접수 → 월간 일정표
- 하나센터 연계 → 안내문 배포 [확인 필요: 협력 하나센터] → 배포 기록
- 쉬운 말 안내 → 남북 말 차이 고려 문구 작성 → 쉬운 말 안내문
- 상담 과정은 신원 노출 없는 문구로 안내, 개인정보는 협약서 별표1 기준 준수

### Ⅱ.3 운영성과 및 피드백 방안
o 설문조사 방법
- 수요조사 → 위탁 개시 직후·연초 실시 → 수요조사 결과표
- 만족도 조사 → 과정 종료 시 종이·모바일 익명 설문 → 만족도 집계표
- 효과 측정 → 상담·교육 전후 같은 문항 → 사전·사후 비교표
- 쉬운 말 문항 사용, 글쓰기 어려운 참여자는 면담으로 대체
o 문항 시안(만족도)
․ 프로그램 내용이 생활에 도움이 되었습니까
․ 강사의 설명을 쉽게 이해했습니까
․ 시간·장소가 참여하기 편했습니까
․ 다시 참여하거나 주변에 권하겠습니까
․ 더 필요한 프로그램은 무엇입니까(서술형)
o 문항 시안(효과)
․ 심리: 요즘 마음이 편안하다 / 고민을 털어놓을 사람이 있다
․ 언어·교류: 남한 말을 알아듣기 쉽다 / 지역 주민과 이야기하기 편하다
- 척도 단계·표준화 검사 사용 여부 [확인 필요: 척도·검사 도구]
o 결과 반영
- 분기 분석 → 문항별 집계·서술 응답 분류 → 분기 설문 분석서
- 개선 회의 → 팀별 결과 검토 → 개선 회의록
- 반영 → 낮은 항목 과정 수정·요청 주제 신설 → 프로그램 개정안
- 중간보고에 계획대비 실적·참여자·강사·설문결과 포함
o 성과지표
- 참여 실적: 과정별 참여 인원·회차 [확인 필요: 목표치]
- 만족도: 과정별 평균 점수 [확인 필요: 목표치]
- 효과: 사전·사후 개선 비율 [확인 필요: 목표치]
- 지속 참여: 다음 과정 재참여 비율 [확인 필요: 목표치]
o 결과보고·성과 제고
- 매년 사업 종료 10일 전까지 결과보고서·사업비 집행 최종 보고서 제출
- 통일부는 연 1회 이상 감독·감사·평가 실시 가능
- 연말 성과평가 → 지표 달성도·설문 종합 → 다음 해 개선계획서
- 2027 평가 결과를 2028 프로그램 편성에 반영
