# 고를 것 — Ⅰ. 개요

「[제안]」은 우리가 새로 내놓는 것이다. 쓸 것에 표시한다. 「[사실]」 줄은 자료에서 온 것이라 목록에 넣지 않았다(초안에서 확인).

## Ⅰ.1 사업 비전
- [ ] 비전: 「마음이 열리고 말이 통하는 남북 이웃」
- [ ] 심리 회복은 소통의 전제이고, 언어 소통은 교류의 통로다. 두 축을 한 사람의 이용 경로로 잇는다.
## Ⅰ.2 사업 목표
- [ ] 목표: 심리 회복과 의사소통 역량을 함께 높여 정착 장애요인을 줄인다.
- [ ] 지표1 상담·검사 참여 인원: [확인 필요: 연간 목표 인원]
- [ ] 지표2 사전·사후 검사 향상자 비율: [확인 필요: 목표 비율]
- [ ] 지표3 의사소통 교육 과정 수·수료율: [확인 필요: 과정 수, 수료율]
- [ ] 지표4 신규 상담·교육 프로그램 수: [확인 필요: 연도별 개수]
- [ ] 지표5 참여자 만족도: [확인 필요: 목표 점수]
## Ⅰ.3 사업 수행전략
- [ ] 2027년(장기계속 1차) 방향은 기반 구축이다. 수요조사와 사전검사를 하고, 심리·언어 과정을 시범 운영한 뒤 정규화한다.
- [ ] 2028년(2차) 방향은 확산·정착이다. 1차 설문·검사 결과로 과정을 보완하고, 지역주민 동반 과정을 넓힌다.
- [ ] 전략1 진단 연계: 검사 결과에 따라 상담·교육 과정을 배정한다.
- [ ] 전략2 혼합 반: 소통 교육의 일부 회차를 지역주민과 함께 진행한다.
- [ ] 전략3 환류: 분기별 설문·검사 결과로 다음 분기 과정을 조정한다.
- [ ] 1월: 인수인계, 사무편람 작성, 수요조사
- [ ] 2~11월: 상담·교육 정규 운영, 분기별 사전·사후 검사
- [ ] 중장기: 2년간의 운영 기록을 표준 과정안으로 묶는다.
## Ⅰ.4 제안의 특장점
- [ ] 특장점1: 검사로 시작하는 맞춤 지원
- [ ] 이 방식을 정착 상담에 옮겨 검사·상담·교육을 하나의 기록으로 잇는다.
- [ ] 특장점2: 말 없이 여는 치유 기법
- [ ] 말로 털어놓기 어려운 초기 상담에서 그림 활동을 먼저 쓴다.
- [ ] 특장점3: 소통·갈등조정 교육 역량
- [ ] 신규 상담지원·교육 프로그램(공고 Ⅱ.5 평가 우대)
- [ ] 마음 그림 첫 상담 → 그림·색 정서진단 후 1:1 해석 상담 → 개인 상담기록지
- [ ] 남북 말 사전 만들기 → 일상·직장 말의 차이를 모아 풀이 → 참여자 제작 낱말집
- [ ] 갈등 장면 바꿔 말하기 → 직장·이웃 사례 역할극과 조정 대화 연습 → 회기별 활동지
- [ ] 우리 이야기 AI 동화 → 정착 이야기를 동화로 엮기 → 동화 모음집
- [ ] 남북 이웃 대화 모임 → 북한이탈주민·지역주민 짝 대화 → 회차별 설문 결과
- [ ] 장기 비전: 「검사로 이해하고 말로 잇는 정착 지원 표준 모델」
- [ ] 1단계(2027): 과정 시범·검증, 사전·사후 검사 기록 축적
- [ ] 2단계(2028): 효과가 확인된 과정 정규화, 진행자 매뉴얼 작성
- [ ] 구성사 역할: [확인 필요: 구성사별 역할분장]
