# 고를 것 — Ⅰ. 개요

「[제안]」은 우리가 새로 내놓는 것이다. 쓸 것에 표시한다. 「[사실]」 줄은 자료에서 온 것이라 목록에 넣지 않았다(초안에서 확인).

## Ⅰ.1 사업 비전
- [ ] 비전 「마음을 잇고 말을 잇는 남북 소통의 숲」 — 거점은 상담센터 마음숲
- [ ] 마음 회복: 정착 장애요인 해소
- [ ] 말 소통: 말·문화 차이 갈등 극복
- [ ] 함께 어울림: 지역주민과 교류 확대

## Ⅰ.3 사업 수행전략
- [ ] 수행전략: 심리검사 → 상담·치유 → 의사소통 교육을 한 경로로 운영한다.
- [ ] 2027년(1차) 기반 구축: 수요조사로 요구 파악, 기존·신규 과정 시범 운영
- [ ] 2028년(2차) 확산: 1차 설문·실적으로 과정 개편, 지역주민 동반 과정 확대
- [ ] 중장기: 2년 기록을 상담·교육 매뉴얼로 정리해 통일부에 제출
- [ ] 종합 추진일정(매년 같은 순환)
- [ ] 1분기 수요조사·모집 → 2~3분기 정규·신규 과정 → 4분기 설문 분석·차년 편성
- [ ] 공고 위탁운영 범위 대응
- [ ] 심리상담·검사·치유·코칭 → 진단 기반 개인·집단상담(Ⅱ.2 프로그램 운영 계획)
- [ ] 의사소통 교육 등 교육과정 → 남북 말·문화 차이 소통교육 과정(Ⅱ.2)
- [ ] 관련 홈페이지 운영 → 일정·신청·결과 게시(Ⅴ. 홍보방안)
- [ ] 위탁 시설물 유지 관리 → 마음숲·강의실 정기 점검·기록(Ⅳ.2)
- [ ] 통일부 요청 사항 → 접수·처리 기록, 수시보고(Ⅱ.3)
## Ⅰ.4 제안의 특장점
- [ ] 특장점 1. 진단부터 치유까지
- [ ] 첫 만남 검사 → 해석상담 → 개인·집단 치유 → 사후 검사로 변화를 확인한다.
- [ ] 특장점 2. 말·문화 차이 소통 경험
- [ ] 이 경험으로 남북한 낱말·표현 차이와 갈등 상황을 다루는 소통교육을 설계한다.
- [ ] 특장점 3. 신규 상담·교육 과정
- [ ] 마음 지도 그리기 → 미술·도형심리로 정착 스트레스를 그림으로 풀고 해석상담 → 그림 기록지·해석지
- [ ] 강점 정착 코칭 → DISC·홀랜드 검사 후 개인 정착 계획 수립 → 코칭 기록지·정착 계획서
- [ ] 남북 말 사전 만들기 → 북한이탈주민·지역주민이 일상 낱말을 서로 풀이 → 낱말집
- [ ] 말 다리 놓기 역할극 → 직장·병원·관공서 상황 대화 연습 → 상황별 대화 카드
- [ ] 마음숲 이웃 과정 → 지역주민이 경청·소통 기초를 배우고 교류 모임에 동행 → 수료 명단·활동일지
- [ ] 내 이야기 AI 동화 → AI 도구로 정착 이야기를 동화로 제작 → 동화 모음집
- [ ] 특장점 4. 지속 가능한 장기계획
- [ ] 1년차 시범·검증 → 2년차 표준화 → 이후 운영 매뉴얼·검사 해석 도구로 남긴다
- [ ] 이를 바탕으로 사업기간 이후 북한이탈주민 소통 도우미 양성 과정으로 넓힌다
- [ ] 장기 비전: 마음숲을 남북 주민이 함께 쓰는 지역 소통 거점으로 만든다
