## 남은 문제 (정확히)
1. (기준 3·6) 필요성의 근거가 가상이다. 실제 기관 자료(참여 청소년 면담, 학교 교육과정, 마음쉼터 기록)와 공공 통계(저소득·다문화)가 들어오기 전에는 설득력이 올라가지 않는다. 지어서 채우지 않았다.
2. (기준 6) 본문 문장 안에서는 어느 수치가 가상인지 보이지 않는다. 표시하면 제출 때 모두 지워야 해서 안내서 7장에 목록으로 두었다. 이 방식이 맞는지 판단이 필요하다.
3. (기준 7) 7-1 칸이 길다. 줄이려면 「운영 방법을 이렇게 정한 이유」와 「필요와 대응」의 겹침을 사람이 정리해야 한다.
4. (기준 7) 참여기관 ② 일정표 제목이 쪽 끝에 남는 것과 7-2 표의 작은 글자는 양식 칸 크기 때문이며 내용을 줄이지 않으면 해결되지 않는다.
5. (기준 2) 가상 기관 설정의 자연스러움은 수치 정합성만 시험했다. 외부 검토가 필요하다.
6. 한글 프로그램으로 직접 열어 쪽 경계를 보는 확인은 사람이 해야 한다(제가 본 것은 한글이 만든 PDF).
