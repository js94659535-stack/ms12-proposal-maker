# 고를 것 — Ⅱ. 사업운영계획

「[제안]」은 우리가 새로 내놓는 것이다. 쓸 것에 표시한다. 「[사실]」 줄은 자료에서 온 것이라 목록에 넣지 않았다(초안에서 확인).

## Ⅱ.1 일반 현황
- [ ] 조직: 사업총괄책임자 아래 상담지원팀·소통교육팀·운영지원팀을 둔다.
- [ ] 사업총괄책임자: 일정·품질 관리, 통일부 보고·협의 창구 [확인 필요: 성명·경력]
- [ ] 상담지원팀(4층 상담센터 마음숲): 검사·상담·치유·코칭, 상담기록 관리 [확인 필요: 인원·자격]
- [ ] 소통교육팀(4층 강의실): 소통교육 과정, 강사 섭외·교안 [확인 필요: 인원·강사]
- [ ] 운영지원팀: 모집·홍보, 홈페이지, 시설물 관리, 설문·보고 [확인 필요: 인원]
- [ ] 북한이탈주민 출신 상담보조 채용 [확인 필요: 인원], 투입 전 직무교육 → 이수 기록
## Ⅱ.2 프로그램 운영 계획
- [ ] 편성 원칙: 수요조사로 콘텐츠를 정하고 분기 설문으로 고친다
- [ ] 사전 수요조사 → 하나센터·센터 이용자 대상 희망 주제·시간대 조사 → 수요조사 결과표
- [ ] 편성 회의 → 결과표로 과정·시간대·정원 조정 → 연간 편성표
- [ ] 분기 설문 반영 → 낮은 문항 회기 교안 수정, 요구 주제 추가 → 교안 수정 이력표
- [ ] 공간별 테마 [확인 필요: 통일부와 사용 공간·시간 협의]
- [ ] 4층 상담센터 마음숲 「마음 회복」: 검사·개인·집단상담
- [ ] 4층 강의실 「말 잇기」: 소통교육
- [ ] 3층 미술실·7층 소망실 「표현·쉼」: 치유·코칭
- [ ] 4층 요리교실·6층 평화통일도서관 「함께」: 교류·체험
- [ ] 1층 대강당·특별전시관 「나눔」: 성과 공유 행사
- [ ] 상담·치유 영역(상담지원팀): 정착 장애요인 해소·심신건강 회복
- [ ] 진단 기반 개인·집단상담 → 정서·적응 검사와 해석 상담 후 개인·집단상담 연결 → 검사 결과지·상담 기록지
- [ ] 북한이탈주민 / 마음숲 / 상시 예약제, 집단 [확인 필요: 기수·회기·정원]
- [ ] (신규) 그림으로 여는 마음 → 감정 그림카드·도형심리로 감정 표현 → 작품·활동 기록지
- [ ] 북한이탈주민 / 3층 미술실 / [확인 필요: 기수·회기]
- [ ] (신규) 정착 강점 코칭 → DISC·홀랜드 검사로 강점 확인 후 취업·생활 목표 코칭 → 개인 실행계획서
- [ ] 북한이탈주민 청년·구직자 / 7층 소망실 / [확인 필요: 기수·회기]
- [ ] (신규) 가족 마음잇기 → 부모 양육태도·자녀 정서 검사 해석과 가족 대화 연습 → 가족 상담 기록지
- [ ] 북한이탈주민 가족 / 상담센터 마음숲 / 주말 [확인 필요: 기수·회기]
- [ ] 소통교육 영역(소통교육팀): 말·문화 차이로 인한 소통 어려움·갈등 극복
- [ ] 남북 말·문화 차이 소통교육 과정 → 외래어·생활 표현·직장 대화 차이 학습과 역할극 → 교안·사전사후 평가지
- [ ] 북한이탈주민 / 4층 강의실 / 평일 저녁반·주말반 [확인 필요: 기수·회기]
- [ ] (신규) 갈등조정 대화교실 → 직장·이웃 갈등 사례로 대화 연습 → 사례 실습지
- [ ] 북한이탈주민·지역주민 함께 / 4층 강의실 / [확인 필요: 기수·회기]
- [ ] (신규) 생활문서 읽기 → 공문서·계약서·안내문 읽기와 질문 연습 → 학습 기록지
- [ ] 북한이탈주민 / 평화통일도서관 / [확인 필요: 기수·회기]
- [ ] (신규) 청소년 말 코칭 → 언어 메타인지 코칭으로 교과 어휘 학습 지원 → 개인 학습 기록지
- [ ] 북한이탈주민 자녀 / 4층 강의실 / 방학 집중반 [확인 필요: 회기]
- [ ] 교류·체험·행사(신규): 북한이탈주민과 지역주민이 함께 참여
- [ ] 밥상 대화 → 남북 가정 음식을 함께 만들며 음식 이름·말 차이 나누기 → 레시피 카드·소감지
- [ ] 4층 요리교실 / 월별 운영 [확인 필요: 회차·정원]
- [ ] 말동무 짝꿍 → 북한이탈주민·지역주민이 짝을 지어 대화·생활 정보 교환 → 대화 일지
