## Ⅰ. 개요
### Ⅰ.1 사업 비전
o 남북주민 소통 기반 마련과 남북통합 문화 확산이 목적이며, 심리 상담·치유와 의사소통 교육이 수단이다
o 비전: 「마음을 열고 말을 잇는 남북통합의 첫걸음」
o 목적① 심리 안정: 검사→상담→치유를 한 흐름으로 묶어 정착 장애요인을 줄인다
o 목적② 소통 역량: 남북 언어·문화 차이로 생기는 오해를 교육으로 푼다
o 목적③ 함께 쓰는 공간: 상담센터 마음숲과 강의실을 지역주민도 오는 소통 공간으로 연다

### Ⅰ.3 사업 수행전략
o 2027년(1차) 기반: 수요조사·사전검사로 과정 편성, 신규 과정 시범 운영
o 2028년(2차) 확산: 1차 설문·검사 결과로 과정 보완, 지역주민 함께 과정 확대
o 중장기: 검증된 과정을 표준 운영안으로 정리해 부 승인 후 다음 사업에 넘긴다
o 전략: 아래 세 가지를 2년 내내 적용
- 진단 먼저: 검사 결과로 과정 배정
- 짝 운영: 상담·소통 교육 한 묶음
- 분기 개선: 설문·검사로 과정 수정
o 분기 종료 후 14일 이내 중간보고, 매년 종료 10일 전 결과보고
o 분기 흐름: 1분기 모집·사전검사 → 2·3분기 본과정 → 4분기 사후검사·결과보고
o 위탁운영 범위 맞대기
- 심리 상담·검사·치유·코칭 → 마음숲에서 검사·개별상담·집단치유·코칭 운영(Ⅱ.2)
- 의사소통 교육과정 → 강의실에서 남북 언어·문화 차이 교육 운영(Ⅱ.2)
- 홈페이지 운영 → 일정·신청·결과 게시, 온라인 신청 접수(Ⅴ)
- 위탁 시설물 유지 관리 → 마음숲·강의실 정기 점검과 기록(Ⅳ.2)
- 통일부 요청 사항 → 요청 접수·처리 후 수시보고로 회신
### Ⅰ.4 제안의 특장점
o 특장점① 검사부터 치유까지 한 기관이 수행
- 종합심리검사·웩슬러지능·성격 등 검사와 해석 상담 직접 수행

- 아이디어: 검사·상담·교육 기록을 1인 1파일로 묶어 2년간 변화 추적
o 특장점② 소통·갈등조정 교육 자산 활용
- 갈등조정지도사·독해력지도사 자격과정 운영

o 특장점③ 신규 상담지원·교육 과정 편성
※ 신규 상담지원·교육 프로그램 포함 시 평가 우대

### 2. 프로그램 운영 계획
o 운영 축: 심리 상담·검사·치유·코칭, 남북 언어·문화 차이 의사소통 교육
- 신규 상담지원·교육 프로그램 포함 시 평가 우대
- 편성: 검증 프로그램에 신규 상담·교육·교류 과정을 영역마다 추가
- 대상 균형: 북한이탈주민 성인·청소년·가족과 지역주민을 과정별로 배정

o 수요조사·설문 반영 콘텐츠 개발
- 착수 수요조사 → 하나센터·참여 희망자에게 관심 주제·시간대 조사 → 수요조사 결과보고서
- 전년도 자료 인수 → 전임 사업자에게 설문 결과 인수를 요청해 분석 → 개선과제 목록
- 분기 설문 → 점수가 낮은 문항의 과정 내용·시간 수정 → 콘텐츠 수정 반영표
- 연차 재편성 → 2027년 설문·수요 결과로 과정 유지·폐지 결정 → 2028년 편성안

o 활용 공간: 4층 상담센터 마음숲(276㎡), 강의실1~4(237㎡), 요리교실(65㎡), 3층 미술실(67㎡), 7층 소망실(53㎡), 1층 대강당(248㎡)
- 마음숲 「마음 회복」: 개별 검사·상담·코칭
- 미술실 「표현 치유」: 집단 미술심리
- 강의실 「말이 통하는 정착」: 의사소통 교육
- 요리교실·소망실 「함께하는 이웃」: 주민 교류·자조모임
- 대강당 「성과 나눔」: 성과공유회

o 마음숲·미술실 심리 상담·치유 과정
- 정착 마음검사 → 종합심리검사·정서검사 실시 후 개별 해석상담 → 개인 검사 해석지
- 개인 심리상담 → 정서문제 회기 상담, 필요 시 의료기관 연계 → 회기별 상담기록지
- (신규) 정착 강점코칭 → 홀랜드·DISC 검사로 진로·직업 강점 탐색 → 개인 정착 코칭계획서
- (신규) 가족 마음상담 → 자녀 심리검사 해석과 부모코칭 → 가족 상담기록지
- (신규) 마음그림 집단 → 감정 그림카드·도형심리로 감정 표현 → 작품·관찰기록지
- 근거: 미술 심리 기반 집단 프로그램(2024), 홀랜드·DISC 자신감 회복(2025), 부모코칭 과정
- 운영: 상담치유팀이 맡고 상담은 예약제 상시, 집단은 기수제 [확인 필요: 운영 요일·기수·회기]

o 강의실 의사소통 교육과정
- 남북 생활언어 교실 → 외래어·생활어휘·억양 차이 학습 → 어휘장, 사전·사후 평가지
- (신규) 생활문해 교실 → 공문서·계약서·안내문 읽기 연습 → 독해력 진단지
- (신규) 갈등조정 대화교실 → 직장·이웃 갈등 사례 역할극 → 대화 실습 기록지
- (신규) 청소년 언어 메타인지 코칭 → 학습어휘·학습전략 개별 코칭 → 학습코칭 기록지
- 근거: 독해력지도사·갈등조정지도사 자격과정, 다문화 학습역량강화(언어 메타인지, 2026)

o (신규) 북한이탈주민·지역주민 교류·체험·행사
- (신규) 남북 말맛 요리교실 → 남북 음식 이름·조리 용어를 함께 익히며 조리 → 남북 요리말 카드
- (신규) 마음나눔 모임 → 소망실에서 수료자 자조모임 운영 → 모임 일지

- 운영: 운영지원팀 주관, 상담·교육 강사 협업 [확인 필요: 개최 시기·모집 인원]
