# 고를 것 — Ⅳ. 비상대책수립

「[제안]」은 우리가 새로 내놓는 것이다. 쓸 것에 표시한다. 「[사실]」 줄은 자료에서 온 것이라 목록에 넣지 않았다(초안에서 확인).

## Ⅳ.1 안전사고 예방대책
- [ ] ① 심리 위기 예방
- [ ] 첫 상담 → 자해·자살 위험, 외상 경험 확인 → 위기선별 기록지
- [ ] 위험군 확인 → 당일 책임자 보고·사례회의 → 사례회의록
- [ ] 집단활동 → 사전 동의, 중단 요청 시 개별상담 전환 → 동의서·전환 기록
- [ ] 위탁 개시 전 → 위기대응 매뉴얼 작성 → 매뉴얼(제26조 사무편람에 포함)
- [ ] 고위험군 → 외부 전문기관 연계 → 연계의뢰서([확인 필요: 연계기관명·협약 여부])
- [ ] ② 개인정보·상담기록 보호
- [ ] 상담기록·검사지 → 잠금 보관, 지정자만 열람 → 열람 기록부
- [ ] ③ 이용 중 사고 예방
- [ ] 프로그램 시작 전 → 비상구·대피 경로 안내 → 운영일지 안내 확인란
- [ ] 운영 인력 → 안전·위기대응 교육 → 이수 기록([확인 필요: 교육 주기])
- [ ] ④ 비상상황별 대응
- [ ] 화재·지진 → 활동 중단, 지정 경로 대피, 인원 확인 → 대피 인원 확인표
- [ ] 응급 환자 → 응급 신고, 보호자 연락 → 사고 경위서
- [ ] 상담 중 자살 위기 → 동석 유지, 책임자 호출·전문기관 연계 → 위기개입 기록지
- [ ] 개인정보 유출 → 접근 차단, 통일부 즉시 통보 → 유출 경위 보고서
- [ ] 보고 체계: 발견자 → 현장 책임자 → 총괄책임자 → 통일부
- [ ] 단계별 담당자: [확인 필요: 공동수급 구성사 역할분장]
- [ ] 분기 중간보고 → 사고·위기 대응 내역 첨부 → 안전관리 실적표
