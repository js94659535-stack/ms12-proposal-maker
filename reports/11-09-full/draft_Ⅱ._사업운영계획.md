## Ⅱ. 사업운영계획

- [제안] 총괄책임자: 협약 이행, 분기 중간보고·결과보고, 통일부 협의 창구
- [제안] 상담치유팀: 마음숲 심리검사·상담·치유·코칭, 상담기록 관리
- [제안] 언어소통교육팀: 강의실 의사소통 교육과정 운영, 강사 섭외·관리
- [제안] 운영지원팀: 홈페이지·시설·회계
- [제안] 인원·자격: [확인 필요: 명단]

o [사실: 기관 자료] 보유 역량: 종합심리검사·웩슬러지능검사, 인지·언어·놀이·미술치료
- [사실: 기관 자료] 자격과정 운영: 갈등조정지도사·놀이심리상담사·독해력지도사
- [사실: 기관 자료] 성인 상담 실적: 경찰청 가족 심리상담, 기아자동차 사원 심리상담
- [제안] 확보: 위 실적에 참여한 상담사를 우선 배치, 부족 분야는 자격과정 수료자 중 선발

o [사실: 기관 자료] 공동수급: (주)마인드스토리(주관), (주)가르침에듀, 아시아밝음공동체
- [제안] 구성사 역할: [확인 필요: 분장]
- [제안] 인력 변경: 사전승인 후 교체, 승인 기간에는 팀 내 대체 담당 지정

### 2. 프로그램 운영 계획
o [사실: 공고 사업내용] 운영 축: 심리 상담·검사·치유·코칭, 남북 언어·문화 차이 의사소통 교육
- [사실: 공고 사업내용] 신규 상담지원·교육 프로그램 포함 시 평가 우대
- [제안] 편성: 검증 프로그램에 신규 상담·교육·교류 과정을 영역마다 추가
- [제안] 대상 균형: 북한이탈주민 성인·청소년·가족과 지역주민을 과정별로 배정

o [제안] 수요조사·설문 반영 콘텐츠 개발
- [제안] 착수 수요조사 → 하나센터·참여 희망자에게 관심 주제·시간대 조사 → 수요조사 결과보고서
- [제안] 전년도 자료 인수 → 전임 사업자에게 설문 결과 인수를 요청해 분석 → 개선과제 목록
- [제안] 분기 설문 → 점수가 낮은 문항의 과정 내용·시간 수정 → 콘텐츠 수정 반영표
- [제안] 연차 재편성 → 2027년 설문·수요 결과로 과정 유지·폐지 결정 → 2028년 편성안

o [사실: 공고 시설현황] 활용 공간: 4층 상담센터 마음숲(276㎡), 강의실1~4(237㎡), 요리교실(65㎡), 3층 미술실(67㎡), 7층 소망실(53㎡), 1층 대강당(248㎡)
- [제안] 마음숲 「마음 회복」: 개별 검사·상담·코칭
- [제안] 미술실 「표현 치유」: 집단 미술심리
- [제안] 강의실 「말이 통하는 정착」: 의사소통 교육
- [제안] 요리교실·소망실 「함께하는 이웃」: 주민 교류·자조모임
- [제안] 대강당 「성과 나눔」: 성과공유회

o [제안] 마음숲·미술실 심리 상담·치유 과정
- [제안] 정착 마음검사 → 종합심리검사·정서검사 실시 후 개별 해석상담 → 개인 검사 해석지
- [제안] 개인 심리상담 → 정서문제 회기 상담, 필요 시 의료기관 연계 → 회기별 상담기록지
- [제안] (신규) 정착 강점코칭 → 홀랜드·DISC 검사로 진로·직업 강점 탐색 → 개인 정착 코칭계획서
- [제안] (신규) 가족 마음상담 → 자녀 심리검사 해석과 부모코칭 → 가족 상담기록지
- [제안] (신규) 마음그림 집단 → 감정 그림카드·도형심리로 감정 표현 → 작품·관찰기록지
- [사실: 기관 자료] 근거: 미술 심리 기반 집단 프로그램(2024), 홀랜드·DISC 자신감 회복(2025), 부모코칭 과정
- [제안] 운영: 상담치유팀이 맡고 상담은 예약제 상시, 집단은 기수제 [확인 필요: 운영 요일·기수·회기]

o [제안] 강의실 의사소통 교육과정
- [제안] 남북 생활언어 교실 → 외래어·생활어휘·억양 차이 학습 → 어휘장, 사전·사후 평가지
- [제안] (신규) 생활문해 교실 → 공문서·계약서·안내문 읽기 연습 → 독해력 진단지
- [제안] (신규) 갈등조정 대화교실 → 직장·이웃 갈등 사례 역할극 → 대화 실습 기록지
- [제안] (신규) 청소년 언어 메타인지 코칭 → 학습어휘·학습전략 개별 코칭 → 학습코칭 기록지
- [사실: 기관 자료] 근거: 독해력지도사·갈등조정지도사 자격과정, 다문화 학습역량강화(언어 메타인지, 2026)
- [제안] 운영: 언어소통교육팀이 기수제로 운영, 직장인반은 저녁 편성 [확인 필요: 기수·회기 수]

o [제안] (신규) 북한이탈주민·지역주민 교류·체험·행사
- [제안] (신규) 남북 말맛 요리교실 → 남북 음식 이름·조리 용어를 함께 익히며 조리 → 남북 요리말 카드
- [제안] (신규) 마음나눔 모임 → 소망실에서 수료자 자조모임 운영 → 모임 일지
- [제안] (신규) 말하기 성과공유회 → 대강당에서 수료생 발표·작품 전시 → 행사 결과보고서
- [제안] 운영: 운영지원팀 주관, 상담·교육 강사 협업 [확인 필요: 개최 시기·모집 인원]

o [제안] 연도별 운영 일정
- [제안] 2027년 상반기: 수요조사, 인수인계, 상담·생활언어 기본과정 개시
- [제안] 2027년 하반기: 신규 코칭·문해·교류 과정 추가, 성과공유회
- [제안] 2028년 상반기: 2027년 설문을 반영한 편성안 적용, 자조모임 확대
- [제안] 2028년 하반기: 성과공유회, 2년 운영 성과 종합

o [제안] 홍보: 홈페이지에 분기 모집 공지, 하나센터에 안내문 배포 요청[확인 필요: 연계 하나센터명], 세부는 Ⅴ장
- [제안] 신청서에 신청 경로 문항 → 경로별 집계표 작성

### 3. 운영성과 및 피드백 방안
o [제안] 설문조사 방법
- [제안] 수요조사: 과정 시작 전 관심 주제·가능 시간대·필요 지원 조사
- [제안] 사전·사후 설문: 첫 회기와 마지막 회기에 같은 문항으로 변화 측정
- [제안] 응답: 종이·온라인 병행, 무기명 작성, 상담기록과 분리 보관

o [제안] 설문 문항 시안(리커트 척도·서술형)
- [제안] (만족) 정착 생활에 도움이 되었다
- [제안] (만족) 설명이 이해하기 쉬웠다
- [제안] (정서) 요즘 마음이 편안하다
- [제안] (정서) 도움 청할 곳이 있다
- [제안] (언어) 남한 생활용어를 이해한다
- [제안] (언어) 대화 중 오해가 줄었다
- [제안] (교류) 이웃과 가까워졌다
- [제안] (운영) 시간·신청 절차가 편리했다
- [제안] (서술) 원하는 새 프로그램은?

※ [제안] 정서·언어 문항은 사전·사후에 같은 문항 사용

o [제안] 설문 결과 반영 절차
- [제안] 분기 집계 → 문항별 평균 산출, 서술 응답 분류 → 분기 설문 분석표
- [제안] 개선 회의 → 점수가 낮은 문항의 과정 내용·시간 수정 → 개선 반영표
- [제안] 신규 주제 발굴 → 서술 응답 주제로 시범 과정 기획 → 신규 과정 기획서

o [사실: 공고 협약서(안) 제8조] 매 분기 종료 후 14일 이내 중간보고(계획대비 실적, 참여자·강사·설문결과 등)
- [사실: 공고 협약서(안) 제10조] 매년 사업 종료 10일 전까지 결과보고서 제출
- [제안] 보고서에 설문 분석표·개선 반영표 첨부

o [제안] 성과평가 지표
- [제안] 참여: 프로그램별 참여 인원 [확인 필요: 연도별 목표]
- [제안] 만족: 만족 문항 평균 [확인 필요: 목표 점수]
- [제안] 정서: 정서 문항 사전·사후 차이 [확인 필요: 목표치]
- [제안] 언어: 생활언어 평가지 사전·사후 차이 [확인 필요: 목표치]
