# 고를 것 — Ⅴ. 홍보방안

「[제안]」은 우리가 새로 내놓는 것이다. 쓸 것에 표시한다. 「[사실]」 줄은 자료에서 온 것이라 목록에 넣지 않았다(초안에서 확인).

## Ⅴ 홍보방안
- [ ] 핵심 메시지: "마음은 편하게, 말은 통하게 - 남북통합문화센터 심리·언어 지원"
- [ ] 홍보 대상: 북한이탈주민, 강서구 등 지역주민, 하나센터 등 연계기관
- [ ] 북한이탈주민의 사진·실명은 서면 동의가 있을 때만 쓰고, 기본은 얼굴·이름을 드러내지 않음
- [ ] 홍보물 관리 → 원본을 목록으로 관리해 통일부에 인도 → 홍보물 관리대장
- [ ] 관련 홈페이지 운영 → 일정·신청·결과 게시(이 절에서 수행)
- [ ] 일정 게시 → 월간 프로그램표 게시 → 월간 일정표 게시물
- [ ] 신청 접수 → 홈페이지 신청 양식으로 접수 → 신청자 명단
- [ ] 결과 게시 → 활동 사진과 익명 후기 게시 → 결과 게시물
- [ ] 운영 기준: [확인 필요: 결과 게시 기한, 기존 홈페이지·SNS 인수 범위]
- [ ] 안내문 하나를 만들어 홈페이지·SNS·문자·센터 게시대에 같은 날 배포
- [ ] 문자 알림 → 수신 동의자에게 일정·마감 안내 → 발송 기록
- [ ] 센터 게시 → 평화통일도서관·대강당 앞에 안내물 비치 → 게시 사진
- [ ] 보도자료 → 신규 프로그램 개시 때 배포 → 보도자료·보도 목록
- [ ] 북한이탈주민: 하나센터와 정착지원 기관을 통해 직접 안내
- [ ] 쉬운 안내문 → 외래어 대신 우리말을 쓰고 낯선 남한 용어에 풀이를 덧붙임 → 쉬운 말 안내문
- [ ] '상담'이라는 말의 부담을 줄이려고 '마음 쉼'으로 표현
- [ ] 협조 기관: [확인 필요: 협조 하나센터명·협조 방식]
- [ ] 지역주민: 평화통일도서관 이용자에게 언어소통 교육을 '남북 말 차이 알기' 체험으로 안내
- [ ] 이야기 콘텐츠 → 동의한 참여자 사연을 익명 AI동화·툰으로 제작 → 카드뉴스
- [ ] 오픈데이 → 4층 상담센터 마음숲을 공개하고 간이 검사를 체험하게 함 → 체험 신청서
- [ ] 신규 프로그램 시범회차 → 사전 신청자 우선 배정 → 시범회차 참여 명단
- [ ] 짝꿍 신청 → 북한이탈주민과 지역주민이 함께 신청 → 동반 신청 명단
- [ ] 효과 측정 → 만족도 설문에 '알게 된 경로' 문항 추가 → 채널별 유입 집계표
- [ ] 홍보 점검 → 채널별 집계표를 중간보고에 붙여 다음 분기 채널 조정 → 홍보 점검표
