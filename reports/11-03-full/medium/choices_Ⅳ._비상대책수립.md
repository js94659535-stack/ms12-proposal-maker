# 고를 것 — Ⅳ. 비상대책수립

「[제안]」은 우리가 새로 내놓는 것이다. 쓸 것에 표시한다. 「[사실]」 줄은 자료에서 온 것이라 목록에 넣지 않았다(초안에서 확인).

## Ⅳ.1 안전사고 예방대책
- [ ] 안전관리 조직: 총괄책임자 아래 안전관리책임자와 공간별 담당자를 둔다.
- [ ] 담당 인력: [확인 필요: 안전관리책임자·공간별 담당자 성명과 소속 구성사]
- [ ] 일상 예방활동
- [ ] 공간 점검 → 회기 전 상담센터 마음숲·강의실의 비상구·소화기 확인 → 일일 안전점검표
- [ ] 대피 안내 → 과정 첫 회기에 대피 경로와 집결지 안내 → 안내 확인 서명부
- [ ] 종사자 교육 → 반기마다 화재 대피·응급처치 교육 → 교육 결과 보고서
- [ ] 심리 위기 예방: 상담 사업이므로 자해·자살 위험을 핵심 안전사고로 관리한다.
- [ ] 초기 선별 → 첫 상담 시 정서 선별검사 → 위기 수준 분류 기록지
- [ ] 사례 회의 → 고위험 사례 발견 당일 상담인력 회의 → 사례회의록
- [ ] 회기 운영 → 탈북·정착 경험을 고려해 발언 강요 금지, 중단 선택권 보장 → 집단상담 운영지침
- [ ] 상담자 보호 → 상담 중 동료 근접 대기, 비상호출 수단 마련 → 상담실 운영수칙
- [ ] 개인정보 사고 예방
- [ ] 상담기록 보관 → 잠금 보관, 접근자 지정, 접속기록 월별 점검 → 접근 관리대장
- [ ] 비상상황 대책: 인지 → 초기 대응 → 보고 → 복구 순서로 처리한다.
- [ ] 화재·재난 → 즉시 중단, 비상구 유도, 소방 신고·센터 통보 → 대피 인원 확인표
- [ ] 응급환자 → 응급처치·구급 신고, 비상연락처 연락 → 사고 경위서
- [ ] 자해·자살 위험 → 상담자 동행으로 안전 확보, 정신건강 전문기관 연계 → 위기개입 기록지
- [ ] 연계 기관: [확인 필요: 지역 정신건강 전문기관명과 협약 여부]
- [ ] 사고 보고 → 당일 유선 보고, [확인 필요: 서면 보고 기한] 내 서면 보고 → 사고 보고서
- [ ] 재발 방지 → 원인 분석, 반기 모의훈련 → 재발방지 대책서
## Ⅳ.2 시설장비유지관리
- [ ] 유지관리 활동
- [ ] 인수 점검 → 개시 시 전임 사업자 인수인계 목록과 실물 대조 → 인수 점검표
- [ ] 일상 점검 → 회기 종료 후 상담실·강의실 정리, 비품 상태 확인 → 공간 점검표
- [ ] 정기 점검 → 월별로 검사도구·기자재 수량과 상태 점검 → 수탁재산 점검 보고서
- [ ] 검사도구 관리 → 검사지 잠금 보관, 판본 확인 → 검사도구 관리대장
- [ ] 고장 처리 → 즉시 사용중지 표시, 센터 관리주체 통보 → 수리 요청 기록부
- [ ] 반납 준비 → 만료 달에 전수 점검 → 인도 목록·운영요령 자료
