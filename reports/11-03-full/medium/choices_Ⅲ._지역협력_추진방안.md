## Ⅲ.1 프로그램의 적절성
- [ ] 대상(북한이탈주민·남북주민 혼합)과 형식(상담·교육·체험)을 엮어 신규 편성
- [ ] 남북 말잇기 교실 → 생활어·직장어 차이를 짝 활동으로 익힘 → 어휘 카드집
- [ ] 마음그림 공방(혼합) → 미술심리 집단활동으로 감정 나누기 → 작품·정서 점검표
- [ ] 남북 밥상 대화(혼합) → 고향 음식을 함께 만들며 대화 → 레시피집·참여 기록지
- [ ] 브리지 소통 모임(혼합) → 협력 카드게임으로 규칙·배려 연습 → 활동 기록지
- [ ] 오해 풀기 워크숍(혼합) → 말·문화 차이 갈등 사례 역할극 → 갈등 사례집
- [ ] 5종 모두 신규, 상담·교육·체험을 분기마다 고르게 배치
- [ ] 회차·정원: [확인 필요: 프로그램별 연간 회차와 정원]
- [ ] 주민 커뮤니티: 수료한 남북 주민을 자조 모임으로 잇는다
- [ ] 말벗 모임 → 남북 주민 짝 정기 만남 → 모임 일지([확인 필요: 모임 주기])
- [ ] 문화활동 연계: 센터 안 다른 세부사업·시설로 참여를 넓힌다
- [ ] 연계 안내 → 수료자에게 다른 세부사업 프로그램 신청 도움 → 연계 기록부
- [ ] 함께 읽기(평화통일도서관) → 독해력 지도 경험을 살린 독서 모임 → 독서 기록지
- [ ] 수요 반영: 신청·회차·분기 세 시점에서 의견을 받아 다음 분기에 반영한다
- [ ] 사전 수요조사 → 신청서에 희망 주제·시간대 문항 → 수요조사 결과표
- [ ] 회차 만족도 설문 → 분기별로 모아 개선점 정리 → 분기 반영표
## Ⅲ.2 지속가능성 및 기대효과
- [ ] 하나센터·지역단체와 의뢰·출장·보급 세 갈래로 협조한다
- [ ] 협력 하나센터: [확인 필요: 협력 하나센터 이름·협약 여부]
- [ ] 상담 의뢰 → 하나센터 의뢰자를 상담 후 결과 회신 → 의뢰·회신 기록지
- [ ] 찾아가는 말잇기 교실 → 하나센터·지역단체로 출장 운영 → 운영 결과 보고서
- [ ] 콘텐츠 꾸러미 → 활동지·어휘 카드집 묶음, 통일부 승인 후 보급 → 보급처 목록
- [ ] 지역 자원: 센터 공간과 기관 양성과정을 지역주민에게 연다
- [ ] 소통 도우미 양성 → 주민에게 갈등조정 기초 교육 → 수료자 명단·활동 기록
- [ ] 강서구 협력 단체: [확인 필요: 지역단체 이름·협약 여부]
- [ ] 참여계획: 북한이탈주민 상담에서 시작해 혼합 활동, 주민 모임으로 넓힌다
