# 고를 것 — Ⅴ. 홍보방안

「[제안]」은 우리가 새로 내놓는 것이다. 쓸 것에 표시한다. 「[사실]」 줄은 자료에서 온 것이라 목록에 넣지 않았다(초안에서 확인).

## Ⅴ 홍보방안
- [ ] 핵심 메시지 「마음은 숲에서 쉬고, 말은 함께 맞춘다」를 모든 홍보물 머리에 같은 문구로 넣는다.
- [ ] 현장 기록 → 운영 당일 사진(얼굴 비노출)과 한 줄 후기 수집 → 현장 기록지
- [ ] 콘텐츠 가공 → 기록지를 카드뉴스·짧은 영상·소식 글로 제작 → 채널별 게시물
- [ ] 동시 배포 → 홈페이지·SNS·문자 알림·협력기관 게시판에 같은 날 게시 → 배포 기록표
- [ ] 남북 낱말 한 컷 → 언어소통교육에서 다룬 생활 낱말 차이를 한 컷 이미지로 연재 → 연재 게시물
- [ ] 생성형 AI로 카드뉴스 초안과 자막을 만들고, 담당자가 검수한 뒤 게시해 제작 시간을 줄인다.
- [ ] 북한이탈주민: 「마음 이야기, 비밀은 지켜집니다」 → 정착지원 기관 게시, 문자 알림, 쉬운 말 안내지
- [ ] 지역주민: 「이웃과 말이 통하는 자리」 → 평화통일도서관·센터 게시대, 지역 커뮤니티 SNS
- [ ] 청소년·가족: 「우리 가족 말·마음 맞추기」 → 학교·가족센터 안내
- [ ] 모집 공고에 참여 자격과 선정 방법을 같은 양식으로 밝히고, 두 대상에게 동시에 알린다.
- [ ] 신규 프로그램 맛보기 → 신규 상담지원·교육 프로그램 개강 전 공개 체험 운영 → 체험 명단·신청 전환 기록
- [ ] 마음숲 열린 날 → 지역주민에게 상담센터를 공개하고 간이 심리검사 체험 제공 → 체험 기록지·만족도 설문
- [ ] 지표는 채널별 조회·도달, 신청자 수, 신청 경로(설문 「어떻게 알았나」 문항), 재참여 비율로 한다. 목표치는 [확인 필요: 연도별 홍보 목표치]로 둔다.
- [ ] 분기 보고에 홍보 지표를 붙이고, 반응이 낮은 채널은 다음 분기에 메시지와 채널을 바꾼다 → 분기 홍보 점검표
- [ ] 북한이탈주민의 얼굴·실명·출신지는 노출하지 않는다. 사진·후기는 서면 동의를 받은 것만 쓴다 → 초상·후기 이용 동의서
