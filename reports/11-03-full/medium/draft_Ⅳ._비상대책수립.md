## Ⅳ. 비상대책수립

### Ⅳ.1 안전사고 예방대책

o [제안] 안전관리 조직: 총괄책임자 아래 안전관리책임자와 공간별 담당자를 둔다.
- [제안] 담당 인력: [확인 필요: 안전관리책임자·공간별 담당자 성명과 소속 구성사]

o [제안] 일상 예방활동
- [사실: 공고 제20조] 이용자 안전사고에 대비해 손해보험에 가입하고 보험증권 원본을 제출한다.
- [제안] 공간 점검 → 회기 전 상담센터 마음숲·강의실의 비상구·소화기 확인 → 일일 안전점검표
- [제안] 대피 안내 → 과정 첫 회기에 대피 경로와 집결지 안내 → 안내 확인 서명부
- [제안] 종사자 교육 → 반기마다 화재 대피·응급처치 교육 → 교육 결과 보고서

o [제안] 심리 위기 예방: 상담 사업이므로 자해·자살 위험을 핵심 안전사고로 관리한다.
- [사실: 기관 자료] 장덕중 「자살예방 생명존중」 프로그램 운영(2021)
- [제안] 초기 선별 → 첫 상담 시 정서 선별검사 → 위기 수준 분류 기록지
- [제안] 사례 회의 → 고위험 사례 발견 당일 상담인력 회의 → 사례회의록
- [제안] 회기 운영 → 탈북·정착 경험을 고려해 발언 강요 금지, 중단 선택권 보장 → 집단상담 운영지침
- [제안] 상담자 보호 → 상담 중 동료 근접 대기, 비상호출 수단 마련 → 상담실 운영수칙

o [제안] 개인정보 사고 예방
- [사실: 공고 별표1] 개인정보보호법 제29조에 따른 관리적·기술적 안전성 확보조치 의무가 있다.
- [제안] 상담기록 보관 → 잠금 보관, 접근자 지정, 접속기록 월별 점검 → 접근 관리대장

o [제안] 비상상황 대책: 인지 → 초기 대응 → 보고 → 복구 순서로 처리한다.
- [제안] 화재·재난 → 즉시 중단, 비상구 유도, 소방 신고·센터 통보 → 대피 인원 확인표
- [제안] 응급환자 → 응급처치·구급 신고, 비상연락처 연락 → 사고 경위서
- [제안] 자해·자살 위험 → 상담자 동행으로 안전 확보, 정신건강 전문기관 연계 → 위기개입 기록지
- [제안] 연계 기관: [확인 필요: 지역 정신건강 전문기관명과 협약 여부]
- [사실: 공고 제9조] 언론 보도와 중요 민원은 수시로 통일부에 보고한다.
- [제안] 사고 보고 → 당일 유선 보고, [확인 필요: 서면 보고 기한] 내 서면 보고 → 사고 보고서
- [제안] 재발 방지 → 원인 분석, 반기 모의훈련 → 재발방지 대책서

### Ⅳ.2 시설장비유지관리

o [사실: 공고 위탁운영 범위] 위탁 시설물 유지 관리는 공통 위탁사무에 포함된다.
o [사실: 공고 제11조] 선량한 관리자의 주의의무를 지고, 수탁재산을 정기 점검해 결과를 보고한다. 주요 장비를 구입·폐기할 때는 사전 승인을 받는다.

o [제안] 유지관리 활동
- [제안] 인수 점검 → 개시 시 전임 사업자 인수인계 목록과 실물 대조 → 인수 점검표
- [제안] 일상 점검 → 회기 종료 후 상담실·강의실 정리, 비품 상태 확인 → 공간 점검표
- [제안] 정기 점검 → 월별로 검사도구·기자재 수량과 상태 점검 → 수탁재산 점검 보고서
- [제안] 검사도구 관리 → 검사지 잠금 보관, 판본 확인 → 검사도구 관리대장
- [제안] 고장 처리 → 즉시 사용중지 표시, 센터 관리주체 통보 → 수리 요청 기록부
o [사실: 공고 제12조] 협약 만료 시 수탁재산을 점검하고 관련 문서·자료와 함께 인도한다.
- [제안] 반납 준비 → 만료 달에 전수 점검 → 인도 목록·운영요령 자료
