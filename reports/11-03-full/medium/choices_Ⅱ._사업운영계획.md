## Ⅱ.1 일반 현황
- [ ] 사업총괄책임자 아래 심리상담·언어교육·교류행사·운영지원 부문을 둔다.
- [ ] 총괄책임자: 사업계획 수립, 분기 중간보고·연말 결과보고, 통일부 협의
- [ ] 심리상담 부문: 마음숲 개인상담·심리검사·코칭, 위기 사례 관리
- [ ] 언어교육 부문: 의사소통 교육과정 운영, 강사 섭외·강의 평가
- [ ] 교류행사 부문: 주민 교류·체험·행사 운영, 홍보물·홈페이지 관리
- [ ] 운영지원 부문: 별도 계정 회계, 시설물 점검, 개인정보 보호 관리
- [ ] 부문별 배치: [확인 필요: 부문별 인원·성명·자격, 겸직 여부]

## Ⅱ.2 프로그램 운영 계획
- [ ] 수요조사 반영 개발 절차
- [ ] 사전 수요조사 → 하나센터·지역단체로 희망 주제·시간대 조사 → 수요조사 결과표
- [ ] 과정 확정 → 수요 상위 주제를 과정·회차에 반영 → 과정 확정 보고서
- [ ] 분기 개편 → Ⅱ.3 설문 결과로 과정 내용 조정 → 개편 내역표
- [ ] 연차 개편 → 2027 운영 결과로 과정 재편 → 2028 운영계획서
- [ ] 균형: 심리와 언어, 북한이탈주민과 지역주민, 개인과 집단을 고루 편성한다.
- [ ] 참여 점검 → 대상별 신청·참여 현황 확인 → 분기 참여자 구성표
- [ ] 본 세부사업 사용 공간: [확인 필요: 통일부와 협의한 배정 공간·시간대]
- [ ] 마음숲 「마음쉼」 상담·검사, 강의실 「말길교실」 언어교육
- [ ] 미술·음악실 「표현치유실」 집단치유, 요리교실·대강당 「어울림마당」 교류
- [ ] 심리 지원 (북한이탈주민 중심)
- [ ] 마음건강 검사 → 종합심리·성격검사 후 개별 해석 상담 → 개인별 해석지
- [ ] 정착 코칭 상담 → 검사 결과로 단기 개인상담·코칭 → 회기별 상담기록지
- [ ] 위기 사례 → 전문기관 연계 → 연계 의뢰서 [확인 필요: 연계 기관]
- [ ] [신규] 마음그림 집단 → 감정 그림카드·도형심리로 정서 표현 → 작품집·척도 결과
- [ ] [신규] 가족 마음돌봄 → 양육태도 검사 후 부모·자녀 상담 → 가족상담 기록지
- [ ] [신규] 마음 안부 전화 → 상담 종결자 사후 안부 확인 → 사후 확인 기록지
- [ ] 언어 소통 교육
- [ ] 남북 말길교실 → 외래어·생활어·존댓말 차이를 실습 → 어휘 노트·수료 명단
- [ ] [신규] 일터 소통 코칭 → DISC 유형 확인 뒤 직장 대화 연습 → 소통유형 보고서
- [ ] [신규] 함께 읽는 우리말 → 자녀와 그림책 읽기·동화구연 → 활동지·낭독 녹음
- [ ] 교류·체험·행사 (지역주민 함께)

- [ ] [신규] 한 상 마음나눔 → 요리교실에서 남북 가정식 함께 조리·대화 → 레시피 카드

- [ ] [신규] 마음·말 나눔회 → 대강당에서 작품 전시·수료식 → 행사 결과보고서

## Ⅱ.3 운영성과 및 피드백 방안
- [ ] 설문조사 방법
- [ ] 사전 설문 → 첫 회기에 기대·어려움 조사 → 사전 설문지
- [ ] 사후 설문 → 마지막 회기에 만족도·변화 조사 → 사후 설문 결과표
- [ ] 응답 방식 → 종이·온라인 병행, 무기명 → 응답 원자료 파일
- [ ] 언어 배려 → 쉬운 우리말 문항, 필요 시 읽어 주기 → 문항 검토 기록
- [ ] 문항 시안(응답: 매우 그렇다~전혀 그렇지 않다)
- [ ] 만족도: 이 과정이 내 생활에 도움이 되었다.
- [ ] 심리 변화: 요즘 마음이 전보다 편안하다.
- [ ] 언어 변화: 내 생각을 말로 전하기가 쉬워졌다.
- [ ] 교류: 북한이탈주민(지역주민)과 대화가 편해졌다.
- [ ] 수요(서술형): 다음에 듣고 싶은 주제와 시간대는?
- [ ] 설문 → 콘텐츠 반영 순환
- [ ] 분기 분석 → 문항별 응답 분포·서술 의견 분류 → 분기 설문 분석표
- [ ] 개선 회의 → 미흡 문항 원인과 수정안 협의 → 개선 회의록·개편 내역표
- [ ] 반영 공개 → 「의견 반영 알림」 홈페이지 게시 → 게시물
- [ ] 사업결과보고
- [ ] 보고 자료 → 계획 대비 실적·참여자·강사 정리 → 분기 실적표
- [ ] 성과평가
- [ ] 지표: 참여 인원, 수료율, 사후 만족도, 척도 사전·사후 변화
- [ ] 목표치: [확인 필요: 지표별 목표 인원·비율]
- [ ] 성과 제고
- [ ] 미달 대응 → 미달 과정의 모집 경로·시간대 조정 → 조정 계획서
- [ ] 연차 반영 → 2027 성과보고서로 과정 존폐 결정 → 2028 운영계획서
