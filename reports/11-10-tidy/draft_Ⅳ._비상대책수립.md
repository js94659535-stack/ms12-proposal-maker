## Ⅳ. 비상대책수립

### Ⅳ.1 안전사고 예방대책

o [제안] ① 심리 위기 예방
- [제안] 첫 상담 → 자해·자살 위험, 외상 경험 확인 → 위기선별 기록지
- [제안] 위험군 확인 → 당일 책임자 보고·사례회의 → 사례회의록
- [제안] 집단활동 → 사전 동의, 중단 요청 시 개별상담 전환 → 동의서·전환 기록
- [사실: 기관 자료] 장덕중 자살예방 생명존중 프로젝트(2021), 종합심리검사·놀이·미술치료 수행
- [제안] 위탁 개시 전 → 위기대응 매뉴얼 작성 → 매뉴얼(제26조 사무편람에 포함)
- [제안] 고위험군 → 외부 전문기관 연계 → 연계의뢰서([확인 필요: 연계기관명·협약 여부])

o [제안] ② 개인정보·상담기록 보호
- [사실: 공고 별표1] 개인정보보호법 제29조 등 안전성 확보조치, 종료 시 파기·반납
- [제안] 상담기록·검사지 → 잠금 보관, 지정자만 열람 → 열람 기록부

o [제안] ③ 이용 중 사고 예방
- [사실: 공고 제20조] 이용자 안전사고 대비 손해보험 가입, 증권 원본 제출
- [제안] 프로그램 시작 전 → 비상구·대피 경로 안내 → 운영일지 안내 확인란
- [제안] 운영 인력 → 안전·위기대응 교육 → 이수 기록([확인 필요: 교육 주기])

o [제안] ④ 비상상황별 대응
- [제안] 화재·지진 → 활동 중단, 지정 경로 대피, 인원 확인 → 대피 인원 확인표
- [제안] 응급 환자 → 응급 신고, 보호자 연락 → 사고 경위서
- [제안] 상담 중 자살 위기 → 동석 유지, 책임자 호출·전문기관 연계 → 위기개입 기록지
- [제안] 개인정보 유출 → 접근 차단, 통일부 즉시 통보 → 유출 경위 보고서
- [제안] 보고 체계: 발견자 → 현장 책임자 → 총괄책임자 → 통일부
- [제안] 단계별 담당자: [확인 필요: 공동수급 구성사 역할분장]
- [사실: 공고 제9조] 중요한 민원·언론 보도는 통일부에 수시보고
- [제안] 분기 중간보고 → 사고·위기 대응 내역 첨부 → 안전관리 실적표

### Ⅳ.2 시설장비유지관리

o [사실: 공고 Ⅱ.7] 4층 상담센터 마음숲(276㎡)·강의실(1~4)(237㎡)
- [제안] 본 사업 사용 공간 확정 → [확인 필요: 통일부 배정 공간 목록]

o [사실: 공고 제3조②] 관리 재산은 전임 사업자와의 인수인계 목록에 따름
- [제안] 위탁 개시 → 목록 대조 점검 → 인수 점검표·현황 사진

o [사실: 공고 제11조] 정기 점검·결과 보고, 장비 구입·폐기 사전 승인, 관리대장 기록
- [제안] 상담 집기·심리검사 도구·교육 기자재 → 품목별 등록 → 장비 관리대장
- [제안] 정기 점검 → 결과 통일부 보고 → 점검표([확인 필요: 점검 주기])
- [제안] 고장 발견 → 사용 중지 표시, 수리 요청 → 수리 요청·처리 기록

o [사실: 공고 제12조] 협약 만료 시 수탁재산 점검·인도, 필요 시 원상회복
- [제안] 만료 달 → 최종 점검·운영요령 정리 → 인계 목록·운영요령 자료
