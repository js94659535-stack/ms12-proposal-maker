## Ⅱ.2 프로그램 운영 계획
- [ ] 콘텐츠 개발 흐름: 수요조사 → 시범운영 → 설문 → 개편
- [ ] 수요조사 → 모집 단계에서 원하는 분야·시간대·말 때문에 겪은 어려움을 조사 → 수요조사 결과표
- [ ] 시범운영 → 신규 프로그램을 짧은 과정으로 먼저 열고 회기 설문 실시 → 시범운영 설문 집계표
- [ ] 개편 → 설문에서 나온 요구로 과정내용·시간대 조정 → 개편 반영표(중간보고 첨부)
- [ ] 공간별 테마
- [ ] 상담센터 마음숲(276㎡) | 마음 회복 | 마음 건강검사, 정착 개인상담, 강점 정착코칭, 가족 마음잇기
- [ ] 미술실(67㎡) | 그림으로 말하기 | 그림으로 여는 마음 집단
- [ ] 강의실(1~4)(237㎡) | 남북 말 잇기 | 생활말 교실, 생활문서 읽기, 갈등 대화, 함께 브리지
- [ ] 요리교실(65㎡) | 밥상 대화 | 남북 밥상 말모음
- [ ] 영상체험실(48㎡) | 내 이야기 | 내 이야기 AI동화
- [ ] 다목적체육관(237㎡) | 놀이로 잇기 | 놀이로 잇는 이웃
- [ ] 대강당(248㎡) | 함께 나누기 | 성과공유회
- [ ] 타 세부사업과 공간 사용 일정은 통일부와 협의해 정한다.
- [ ] 심리지원(신규 상담지원 포함)
- [ ] 마음 건강검사 → 정서·성격·스트레스 검사 후 개별 해석 → 검사결과지·해석상담 기록지
- [ ] 정착 개인상담 → 회기제 상담과 사례관리 → 상담일지·사례관리카드
- [ ] (신규) 그림으로 여는 마음 집단 → 감정 그림카드·도형심리로 감정 표현 → 회기 활동지·작품 기록
- [ ] (신규) 강점 정착코칭 → DISC·홀랜드 검사로 자기이해·진로 설계 → 개인 코칭계획서
- [ ] (신규) 가족 마음잇기 → 부모양육태도·자녀 정서검사 해석, 가족 상담 → 가족별 상담 기록지
- [ ] 언어소통교육(신규 교육 포함)
- [ ] 남북 생활말 교실 → 직장·병원·관공서 장면별 표현 비교 → 장면별 표현 카드·학습지
- [ ] (신규) 생활문서 읽기 → 안내문·계약서·가정통신문을 읽고 요약 → 독해 활동지
- [ ] (신규) 갈등 대화 교실 → 갈등 장면 역할극과 갈등조정 대화법 실습 → 실습 기록지
- [ ] (신규) 자녀 학습 대화 코칭 → 부모가 자녀와 학습·진로 대화법 익힘 → 가정별 대화 계획표
- [ ] 신규 교류·체험·행사(북한이탈주민과 지역주민이 함께 참여)
- [ ] (신규) 남북 밥상 말모음 → 남북 음식을 만들며 음식 이름·말 차이 나눔 → 말모음 카드·레시피집
- [ ] (신규) 함께 브리지 → 남북 주민 한 팀으로 브리지 게임, 규칙 설명·협의 대화 → 경기 기록지
- [ ] (신규) 내 이야기 AI동화 → 정착 이야기를 AI 도구로 동화로 제작 → AI동화 책자
- [ ] (신규) 놀이로 잇는 이웃 → 남북 가족이 사회성 놀이를 함께함 → 소감 기록지·활동 사진
- [ ] (신규) 성과공유회 → 작품·동화·말모음 전시와 참여자 발표 → 행사 결과보고서

## Ⅱ.3 운영성과 및 피드백 방안
- [ ] 설문조사 방법
- [ ] 수요조사 → 모집 시 원하는 분야·시간대 조사 → 수요조사 결과표
- [ ] 사전·사후 설문 → 첫 회기와 마지막 회기에 자기평가 → 변화 비교표
- [ ] 회기 만족도 → 회차 종료 시 짧은 카드 작성 → 회차별 집계표
- [ ] 응답은 무기명이며, 쉬운 말 문항을 쓰고 원하면 담당자가 읽어 준다.
- [ ] 설문 문항 시안

- [ ] 사전·사후 | 요즘 마음이 편안하다 / 남한 사람과 대화할 때 자신 있다 / 안내문을 혼자 읽을 수 있다 | 정도
