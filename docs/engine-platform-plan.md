# 엔진을 플랫폼에 잇는 계획 (10-11)

작성 2026-10-31. 상태: **계획만 — 코드는 아직 건드리지 않았다.**

## 목표

사용자가 하는 일 넷 중 ②까지만 플랫폼에 있다. ③을 잇는다.

```
① 서류 올린다 → ② 공고 고른다 → ③ 초안 받는다 → ④ 빈 데 채운다
   (없음)          (/rfp/ 있음)      (터미널에만)      (없음)
```

다 되면: `/rfp/`에 공고와 기관 서류를 올리고 「초안 만들기」를 누르면, 장마다 초안이 화면에 나오고
제출본·검토본·고를 제안·`[확인 필요]` 목록·검사 결과·그 장의 원가를 본다. 터미널은 쓰지 않는다.

계획서 한 편은 엔진을 재는 시험대다. 「한 편의 값」은 연습 비용이 아니라 **고객 한 편의 원가**다
(목표: **2만 자 한 편 원가 1,000원 이하, 소비자 값 약 5,000원 = 원가의 5배** — 사용자, 10-31. 인수인계서의 1,500원보다 이것이 앞선다).

## 사람이 먼저 정할 것 (멈춤 조건)

1. **생성 API를 누가 부를 수 있게 하나.** 사이트가 열려 있으므로 막지 않고 올리면 **아무나 우리 돈으로 AI를 부른다.**
   이것이 정해지기 전에는 생성 API를 운영에 올리지 않는다.
   - (가) **Cloudflare Access** — 대시보드에서 `/api/draft`와 `/rfp/` 앞에 이메일 로그인을 건다. 코드 없음. 1단계(사장이 대행)에 맞는다. **권함**
   - (나) 운영자 암호 하나 — 암호(Secret)로 두고 화면에서 입력. 코드 조금. 새면 바꿔야 한다
   - (다) 8월 계정 기능을 되살림 — 크다(하루+). 2단계(구독) 때 할 일
2. **Anthropic 키를 Cloudflare 암호(Secret)로 넣기** — 사용자가 대시보드에서 한다. 키는 저장소·채팅에 적지 않는다.
3. **엔진 기본 모델·effort를 정할 실측 승인** — 아래 4단계. 돈이 든다(어림 300원 안팎).
4. **비용 기록에 DB 마이그레이션이 필요하면** — 2단계에서 운영 DB의 표 모양을 본 뒤 묻는다.

## 단계

### 1단계 — 엔진을 서버에서 돌린다 (반나절)

- `functions/api/draft.js` 하나. `POST { rfpText, facts: [{source, text}], project, unit: "Ⅰ" }`.
- **판정은 서버가 다시 한다.** 화면이 보낸 표를 믿지 않고 `readPlan(rfpText, { project })`를 서버에서 다시 돌려
  그 장을 고른다 — 판정은 한 곳(대원칙 ③, 10-08). 화면과 서버가 같은 파일을 import한다.
- `draftSection`을 그대로 부른다. 돌려주는 것: 검토본(draft)·제출본(submit)·고를 제안(choices)·검사·기록.
  파일로 쓰던 것을 응답으로 바꿀 뿐 엔진 코드는 고치지 않는다.
- 모델·effort는 **서버가 정한다**(환경변수, 기본값은 4단계에서). 화면에서 고르지 않는다 — 분량처럼 엔진이 정할 값이다.
- **오래 걸린다.** Ⅰ장 한 번이 출력 1.6만~2.2만 토큰이다. 요청을 열어 둔 채 기다리면 Workers의 시간·CPU 한도에
  걸릴 수 있다. 먼저 `wrangler pages dev`에서 한 장을 돌려 걸리는 시간과 CPU를 잰다.
  걸리면 응답을 흘려보내기(stream)로 바꾼다. 못 재고 정하지 않는다(대원칙 ④).
- 시험: 가짜 클라이언트로 API가 같은 판정·같은 프롬프트를 쓰는지(터미널 도구의 dry-run 결과와 글자 하나 다르지 않은지).

### 2단계 — 막기와 원가 장치 (반나절~하루)

- 1번 결정대로 막는다. 막히기 전에는 운영 배포를 하지 않는다(`main` 푸시 = 배포).
- 호출마다 기록: 시각·장·모델·effort·토큰(입력·캐시 쓰기·캐시 읽기·출력·생각)·원화. 공고·서류·본문은 기록하지 않는다
  (8월 `ai-usage.js`의 규칙 그대로). 실패한 호출도 남긴다 — 실패해도 청구된다.
- 상한 셋을 **호출 전에** 본다: 한 장, 한 편(같은 공고+기관 묶음), **하루 전체(돈 기준)**.
  8월에는 하루 상한이 토큰 기준뿐이었고, 새 계획서를 처음 만드는 동안 한 편 상한이 안 걸려 24%가 빠져나갔다
  (8/22 인수인계서 8절). 이번에는 한 편의 묶음 키를 화면이 아니라 서버가 정한다.
- 막히면 화면이 「상한에 걸림」이라고 말한다 — 8월에는 403을 읽는 자리가 없어 「AI 실패」로 보였다.
- 운영 D1의 `ai_usage_events` 모양을 먼저 본다. 칸이 모자라면 마이그레이션 → **멈추고 묻는다.**

### 3단계 — 화면 (하루)

- `/rfp/`에 **기관 서류 칸**을 더한다(HWP·HWPX·TXT). 글은 브라우저에서 뽑고 글만 보낸다.
- 지금 화면은 「파일은 어디로도 보내지 않습니다」라고 말한다. 생성 때는 **공고와 서류 글이 서버와 Anthropic으로 간다.**
  문구를 고치고, 「초안 만들기」를 누를 때 무엇이 어디로 가는지 한 줄로 밝힌다.
- 장마다 「초안 만들기」, 그리고 「전부(Ⅰ→Ⅴ 차례로)」. 차례로 부르면 공고·기관 블록 캐시가 둘째 장부터 걸린다
  (캐시 5분 — 쉬지 않고 이어 부른다).
- 결과: 제출본 / 검토본([제안]·[사실] 표시) / 고를 제안 / `[확인 필요]` 목록 / fail·warn / 쪽수(권장 대비) / 그 장의 원가.
- 내려받기는 우선 글(.md·.txt). HWP 서식 채우기는 이번 범위 밖(10/31 인수인계서 12절).
- 브라우저로 직접 눌러 본다. 「시험 통과 ≠ 화면에서 됨」(8/22 인수인계서 9절).

### 4단계 — 엔진 기본값을 잰다 (실측, 돈 — 승인 받고)

- 플랫폼 화면에서 **Ⅴ장(홍보, 3쪽) 하나**를 셋으로: Sonnet 5.5 low · Opus 5.5 low · Opus 5.5 medium.
  어림 합계 300원 안팎(셈한 값). 원가·쪽수·fail·글을 견준다.
- 고른 값으로 Ⅰ~Ⅴ 한 편을 한 번 돌려 **한 편 원가를 잰다.** 목표(2만 자 1,000원 이하 = 1만 자 500원 이하)와 견준다.
- 셈한 값(Ⅰ장 실측에서): 지금처럼 Opus medium 약 2,700원 · Opus low 약 1,000원 · Sonnet low 약 500원.
  이 표는 추정이다 — 실측이 나오면 지운다.
- **한 편 4,000원은 안 된다**(사용자, 10-31). 4,000원 어림은 Opus를 생각 많이(high/medium) 쓴 값이고,
  그 59%가 생각 토큰이다. 줄이는 손잡이는 effort·모델·입력 길이다.
- **GPT로 바꾸면 공짜인가 — 아니다.** ChatGPT 회원(구독)은 채팅 화면에서 쓰는 값이고,
  플랫폼 서버가 부르는 API는 따로 토큰마다 청구된다. 8월 플랫폼도 OpenAI API(`gpt-5.6-sol`)로 돌았고
  한 편 평균 1,322원(실측 18건)이 청구됐다. 단가도 출력 $30/1M으로 Opus 5.5($20)보다 비싸다.
  다만 엔진은 클라이언트를 받는 모양이라 OpenAI 길을 붙일 수는 있다 — 4단계 견줌에 넣을지는 사람이 정한다.

- `project.json`(기관이 정한 것)은 지금처럼 화면에 올린다. 화면에서 고치는 칸은 나중이다.
